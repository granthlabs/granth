granth examples

The same database and the same queries in each — only the binding differs.

  • Vanilla JS — subscribe() straight into the DOM
  • React — granth-react, SSR-safe
  • Vue — granth-vue composable
  • Svelte — the store contract, no adapter
  • Solid — createResource off the same subscription
  • No Worker — inline runtime on IndexedDB
Angular needs no adapter either — see the Frameworks guide.
